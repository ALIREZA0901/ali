# راهنمای Umbra

## نصب و اجرا
- این نسخه به صورت قابل حمل (Portable) ارائه می‌شود.
- برای ساخت فایل اجرایی روی ویندوز 10/11:
  1) PowerShell را باز کنید.
  2) به پوشه `BuildScripts` بروید.
  3) فرمان زیر را اجرا کنید:
     ```powershell
     .\build.ps1
     ```
  4) خروجی در پوشه `UmbraPortable` قرار می‌گیرد.
- برای بسته‌بندی نهایی:
  ```powershell
  .\package.ps1
  ```

## نیاز به دسترسی ادمین
Umbra به صورت عادی بدون دسترسی Administrator اجرا می‌شود. هر اقدامی که نیاز به تغییر شبکه داشته باشد (مثل تغییر DNS، تغییر مسیرها، نصب درایور TUN یا اجرای VPN) تنها پس از تأیید شما انجام می‌شود و در صورت نیاز، با دسترسی ادمین اجرا خواهد شد.

## قوانین ایمنی (Safety Rules)
- هیچ تست سنگین (Speedtest یا سنجش پهنای باند) به صورت خودکار اجرا نمی‌شود.
- هر تغییر حساس شبکه (DNS، Route، VPN، NRPT، Load Balance) فقط با کلیک شما و نمایش دیالوگ تأیید انجام می‌شود.
- تست‌های تشخیصی فقط از صفحه Settings بخش Diagnostics قابل اجرا هستند.
- در اولین اجرا، ویزارد اولیه فقط یک بار نمایش داده می‌شود و بعد از آن تستی به صورت خودکار شروع نمی‌شود.
- عملیات دانلود/آپدیت در پس‌زمینه اجرا می‌شود تا رابط کاربری قفل نشود.

## محل ذخیره اطلاعات
- تنظیمات و داده‌ها در مسیر زیر ذخیره می‌شوند:
  `%APPDATA%\Umbra`
- فایل‌های اصلی:
  - `config.json`
  - `profiles.json`
  - `routing_rules.json`
  - `dns_catalog.json`
  - `logs/`
  - `cache/`
